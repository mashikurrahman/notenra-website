# PROJECT-WIDE DESIGN RULES

Maintain one unified visual language across the entire website.

## Style:
Premium enterprise healthcare technology.

## Inspired by:
Apple, OpenAI, Stripe, Linear, Vercel

## Color Palette:
Midnight Navy, Deep Ocean, Teal, Soft Aqua, White

## Visual Principles:
- Human-first
- AI-enhanced
- Editorial
- Minimal
- Premium
- Spacious
- Glassmorphism
- Soft lighting
- Meaningful motion
- Consistent art direction

## Photography:
Use authentic editorial healthcare photography.

## Illustrations:
Use premium AI-generated custom artwork.

## Product UI:
Marketing-quality floating UI components.
Never use raw application screenshots.

Every image, illustration and UI mockup must feel like it belongs to the same design system.
